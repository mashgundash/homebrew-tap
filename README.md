# Tap Homebrew de Quotum

[Quotum](https://quotum.app/) affiche dans la barre de menus de macOS le quota restant de vos outils de codage IA.

```sh
brew install --cask mashgundash/tap/quotum
```

Ce dépôt ne contient que le cask : l'application est téléchargée depuis `updates.quotum.app`, signée Developer ID et notarisée par Apple. Elle se met ensuite à jour d'elle-même.
